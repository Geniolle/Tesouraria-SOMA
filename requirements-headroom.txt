#    - SDK Core apenas:       pip install headroom-ai
#    - Proxy Server:          pip install "headroom-ai[proxy]"
#    - MCP Server:            pip install "headroom-ai[mcp]"
#    - LangChain Integration: pip install "headroom-ai[langchain]"
#    - Outros extras:         [ml], [code], [memory], [vector], [agno], [evals]
#
# 4. Modos de Operação Principais:
#    - Iniciar Proxy Local:   headroom proxy --port 8787
