# Design applicability

Tesouraria-SOMA is a background Python service and command-line application. It has no maintained graphical user interface, design system, or browser flow in this repository.

Visual design, responsive layout, browser accessibility, shadcn, React, and Next.js guidance are therefore not applicable. CLI and operational output should remain concise, structured, safe for logs, and free of secrets.

See [../ARCHITECTURE.md](../ARCHITECTURE.md) for system structure and [quality.md](quality.md) for verification requirements.
